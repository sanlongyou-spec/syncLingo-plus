# RAG 问答评估集（P0-9）

目的：在改动检索/生成任一环时，用**固定问题集**量化"哪类问题答得好/差"，避免凭感觉盲改。
每次改动跑一遍，对比答案正确性、是否命中正确来源、是否幻觉。

## 怎么用
1. 准备：库里至少有评估涉及的会议数据（如"班长的战争：物流/贸易/采购"那场）。
2. 逐题向 Bot / Web 问答提问，按下表 4 个维度人工打分（0/1，或 0–2）：
   - **正确性**：答案与事实一致。
   - **完整性**：覆盖问题要点（对比/聚合题尤其看）。
   - **忠实性**：不编造；资料没有时如实说"未提及"。
   - **来源**：引用了正确的会议/文件（且不重复同一文档）。
3. 记录每题得分 + 失败原因（检索没召回 / 召回了但生成没用 / 幻觉 / 来源错）。
4. 改动后重跑，对比总分与失败分布，定位是"检索环"还是"生成环"的问题。
   （可选：接 RAGAS 自动算 faithfulness / answer_relevancy / context_recall。）

|---|------|---------|
